# Experiment Metadata

This folder keeps metadata needed to interpret the standalone experiment
outputs.

## Files

- `aidev_pr_level_data_dictionary.csv`: column-level metadata for
  `ExtraExperiment/results/pull_request_workload_gate/aidev_pr_level_features.csv`.
- `aidev_pr_level_data_dictionary.md`: readable version of the same data
  dictionary.

The raw AIDev and SWE-bench data are not bundled here. Place external datasets
under `ExtraExperiment/Dataset/` when reproducing the pipeline.
