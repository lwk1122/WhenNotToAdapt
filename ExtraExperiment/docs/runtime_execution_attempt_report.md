## Why The Experiment Was Not Marked Complete

The repository intentionally has no automatic runner for untrusted SWE-bench repositories. Existing runtime scripts perform scheduling, prompt dry runs, recording, validation, and analysis. They do not clone repositories, install dependencies, apply patches, or run tests.

The first-wave manifest explicitly uses `TODO_EXECUTE_IN_APPROVED_ISOLATED_ENV` as the execution placeholder. Recording completed rows without executing the packets and observing metrics would fabricate evidence.

Therefore, the first-wave controlled runtime experiment remains blocked until an approved isolated execution environment is explicitly cleared and the 48 rows are actually executed.
